# specs/ directory

This directory holds Spec-Driven Development documents, one file per
feature, named:

```
specs/<issue-number>-<slug>.md
```

For example, issue #12 ("support tagging todos") maps to
`specs/12-todo-tags.md`.

Spec files are generated by the AI during the `stage:plan` stage, following
[`TEMPLATE.md`](./TEMPLATE.md), and are submitted as a PR. That PR must be
reviewed and merged by a human before the issue is allowed to move into
`stage:implement`.

This is the single source of truth for the whole AI Factory pipeline: the
AI in the implementation stage is only allowed to build against an already
merged spec, and must not reinterpret the raw issue description on its own.
